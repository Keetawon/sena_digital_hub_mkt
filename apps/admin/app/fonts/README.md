Unmodified variable font from the official Google Fonts repository, downloaded on 20 September 2026:

- Source: https://github.com/google/fonts/tree/main/ofl/notosansthai
- File: `NotoSansThai[wdth,wght].ttf` (stored here as `NotoSansThai-Variable.ttf`)

The font includes Thai and Latin and supports weights 100–900. Next.js serves the bundled font locally through `next/font/local`; builds and staff browsers do not need a Google Fonts connection.
